# محكمة الشركات

ارفع القوائم المالية لشركة مدرجة (PDF)، فيقرأها الموقع ويحدد قطاعها ويحسب ما يناسب هذا القطاع من نسب ونماذج، ثم يعرض الأدلة في معرض تفاعلي وينتهي بحكم استثماري: **استثمر، استثمر بحذر، لا تستثمر الآن، لا تستثمر**، مع أسبابه.

مشروع مساق تحليل القوائم المالية.

**جرّبه:** https://awadmustafa764-web.github.io/mahkamat-alsharikat/

## كيف تجرّبه في دقيقتين

1. افتح الرابط واختر إحدى الشركات الخمس الجاهزة، أو ارفع ملف القوائم المالية لأي شركة.
2. أثناء القراءة خمّن ثلاثة أجوبة عن الشركة، ثم اعرض الحكم.
3. صفحة الحكم تعطيك الجواب وأقوى ثلاثة أسباب ضد الشركة وثلاثة معها.
4. «افحص الأدلة بنفسك» يدخلك المعرض: تتنقل بالأسهم أو الماوس، وتفتح أي دليل لترى رقمه ومعادلته وصفحته في التقرير، وتحكم عليه «مقنع» أو «غير مقنع». الميزان في قاعة الحكم يميل مع الأدلة التي تمر بها.
5. في النهاية صكّ قابل للطباعة يجمع حكم النموذج وحكمك.

## من أين يأتي الحكم

| الطبقة | ماذا تفعل |
|---|---|
| القراءة | خدمة صغيرة على Cloudflare ترسل الملف إلى Gemini وتعيد كل بند مع رقم صفحته. الملفات الطويلة تُقتطع في المتصفح إلى تقرير المدقق والقوائم والإيضاحات قبل الإرسال. |
| فحص السلامة | الأصول = الخصوم + حقوق الملكية، مجاميع البنود، حركة النقد بين السنتين، ومطابقات أخرى بهامش تسامح. |
| القطاع | البنوك والتأمين والصناعة والخدمات والاستثمار لكلٍّ نسبها؛ والنسبة التي لا تناسب القطاع تُستبعد مع سبب الاستبعاد. |
| النماذج | Piotroski F-Score (2000)، Altman Z″، مستحقات Sloan، تحليل DuPont، ومقارنة بوسيط القطاع في بورصة فلسطين. |
| تقرير المدقق | الرأي المتحفظ أو المعاكس، الشك في الاستمرارية، فقرات لفت الانتباه، وأمور التدقيق الرئيسية تخفض الحكم. |
| الحكم | حساب ثابت بلا ذكاء اصطناعي: نفس القوائم تعطي نفس الحكم دائماً. |

الذكاء الاصطناعي يقرأ الأرقام فقط. كل الحسابات والحكم يجريها محرّك JavaScript مكشوف في `src/engine/`.

## كيف نعرف أن الأرقام صحيحة

- **136 اختباراً آلياً** تعمل قبل كل نشر؛ إن فشل واحد لا يُنشر الموقع.
- **مطابقة مستقلة في Excel:** النسب نفسها محسوبة بمعادلات Excel في `excel/` وتُقارن بالموقع.
- **تدقيق أعمى:** 75 بنداً من الشركات الخمس أعيدت قراءتها من التقارير الرسمية دون النظر إلى البيانات: 75 من 75 مطابقة (`data/sources/audit-2026-11-24.md`).
- **القارئ نفسه مقيس:** لا يُستخدم إلا موديل قرأ ملفاً مُدققاً يدوياً بلا أي بند خاطئ (التأمين الوطنية 43 من 43، دواجن فلسطين 2025: 73 بنداً بلا خطأ).
- **مثال محلول يدوياً** في `docs/worked-example.md`.

## حدود الموقع

- الحكم تعليمي ومبني على القوائم المنشورة وحدها؛ لا يأخذ سعر السهم أو التقييم السوقي في الحساب.
- القراءة المجانية لها حصة يومية عند Google. الملف الذي قُرئ مرة يُحفظ، فإعادة رفعه تفتح فوراً من أي جهاز. الشركات الخمس الجاهزة تعمل دائماً.
- التقارير الممسوحة ضوئياً بالكامل تُقرأ، لكن الأفضل رفع القوائم المالية مع تقرير المدقق.

## تشغيله محلياً

```
npm install
npm run dev
```

ثم افتح http://localhost:5173. الاختبارات: `npm test`.

## الملفات

| المسار | المحتوى |
|---|---|
| `src/engine/` | محرك التحليل: النسب، القطاعات، النماذج، فحص السلامة، الحكم |
| `src/stages/`، `src/exhibit/` | الواجهة والمعرض ثلاثي الأبعاد |
| `src/app/trim.js` | اقتطاع صفحات القوائم من التقرير السنوي |
| `worker/` | خدمة القراءة على Cloudflare (المفتاح سرّ داخلها فقط) |
| `data/companies/` | الشركات الخمس، كل بند برقم صفحته |
| `data/SOURCES.md` | روابط التقارير الرسمية المصدر |
| `excel/` | المطابقة المستقلة في Excel |
| `tests/` | الاختبارات |
